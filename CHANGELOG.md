## [4.2.0] — 2026-11-27 (Performance Overhaul, Activity-Aware Offline-First Sync, Daily Notes Archive, Physical Note Scanner/OCR, Integrated PDF Studio & Optional RTX 5050 GPU Service)
- **§2 Comprehensive Performance Overhaul (`PLANADAY_PERFORMANCE_AUDIT.md`):** Lazy-loaded all 28+ non-initial views in `App.tsx` and `AllInOneView.tsx` and switched `vite.config.ts` to function-based `manualChunks(id)` isolating `appCore`, `vendor`, `pdfEngine`, `ocrEngine`, `pdfStudio`, `scannerStudio`, and all studio chunks — reducing cold-boot eager JS by **−39.1% raw / −34.0% gzip** (`1.32 MB` → `806.1 KB` raw / `249.8 KB` gz) with zero lazy chunks preloaded on boot. Added non-destructive Dexie v3 compound indexes + `searchIndex` table, incremental inverted trigram FTS engine (`InvertedSearchIndex`: **100,000 records searched in `2.01 ms` p50 / `14.32 ms` p95**, `0.19 ms` incremental upsert), bounded LRU ObjectURL cache (`blobCache.ts`), `VirtualList`, ~60× fewer idle notification scans in `AppContext.tsx`, and SQLite composite indexes + 16 MB page cache PRAGMAs.
- **§3 True Offline-First + Activity-Aware Intelligent Sync:** Upgraded `src/core/sync.ts` so all edits save locally first (`0.62 ms` p50 / `1.43 ms` p95 CRUD) while background sync detects active interaction and defers automatically until ~10s of inactivity (capped at `120s` max postponement), yields multi-blob transfers if the user resumes typing, and supports `smart`, `manual`, `scheduled`, `continuous`, `offline`, `wifiOnly`, `chargingOnly`, and `selectiveWorkspaceIds` policies via a live Settings Sync Dashboard.
- **§4 Unified Daily Notes Archive (Zero Duplication):** Created `src/core/dailyNotes.ts` and unified Today Spread's Daily Notes & Margin Scratchpad with the new **Notes → 📅 Daily Notes** tab referencing the exact same canonical `note` record, complete with month-calendar navigation, 6 daily categories, jump-to-daily-planner navigation, 1-click Task/Project/Diary/Permanent-Knowledge conversion, and automatic bidirectional backlinks.
- **§5 Physical Note Scanner & Handwriting OCR Studio:** Added `src/core/documentScanner.ts` and `src/modules/studio/DocumentScannerView.tsx` with camera capture, multi-page scan queues, automatic Sobel edge detection, 4-point projective homography warp, integral-image shadow reduction, crisp B&W mode, table-to-CSV extraction, hybrid offline `tesseract.js` Web Worker + optional RTX 5050 GPU OCR, `<70%` low-confidence word flags with mandatory manual review confirmation before saving to Laboratory records, and original scan preservation.
- **§6 Optional Self-Hosted NVIDIA RTX 5050 GPU Acceleration:** Added optional Dockerized FastAPI+CUDA microservice (`gpu-service/`), Dockge-ready `docker-compose.gpu.yml` overlay (`GPU_MEMORY_LIMIT_MB=6144`, persistent `/models` volume), authenticated `server/gpuBridge.ts` + `/api/gpu/*` routes, Settings GPU Acceleration & Privacy Opt-In Dashboard, and automatic offline on-device fallback.
- **§7 Integrated PDF Reader, Editor & Secure Redaction Studio:** Added `src/core/pdfEngine.ts` and `src/modules/studio/PdfStudioView.tsx` (`pdfjs-dist` + `pdf-lib`) supporting offline reading (single/spread/continuous, zoom, bookmarks, reading progress, full-text search), highlights/ink/comments/stamps/signatures, AcroForm reading & filling, true structural page rotate/crop/duplicate/add/delete/reorder/merge/split/image-insert, scanned-page OCR indexing into Global Search, and **true irreversible secure redaction** removing underlying secret text bytes.
- **§8 & §9 Size Audit & Store Distribution Readiness:** Published `PLANADAY_SIZE_AND_COMPLETENESS_AUDIT.md` (explaining APK vs. Electron size delta and verifying all 45 modules / `33,235` lines / 0 stubs) and `docs/STORE_DISTRIBUTION.md`; hardened Windows Electron packaging (`.pdf`/`.dmtheme` file associations, multi-window, native print, NSIS/MSIX metadata) and Android CI (`versionCode 420` / `4.2.0`, R8 shrinking, PDF/image `VIEW`/`SEND` intent filters, optional secret-gated AAB workflow).
- **Verification:** `14/14` Vitest suites, **`186/186` tests PASS**; `0` TypeScript errors; `0` Chrome 74 syntax issues; `0` `localStorage`; `0` native dialogs; `0` `eval`.
