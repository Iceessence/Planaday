## [4.1.0] — 2026-11-24 (Developer-Verified Repair & Hardening Release — Pending Independent Verification)
- **Canonical Project Ledger:** Added `PLANADAY_MASTER.md`, `PLANADAY_DEVELOPMENT_ROADMAP.md`, `PLANADAY_WORKING.md`, `PLANADAY_FEATURE_MATRIX.csv` (652 rows with 29 shifted cells repaired), `PLANADAY_ISSUES.md` (28 tracked issues), `PLANADAY_EXPANSION_CATALOG.md` (56 packages `PF-01`–`PF-56`), `PLANADAY_TEST_RESULTS.md`, and `PLANADAY_RELEASE_CHECKLIST.md`.
- **P0 Data Integrity & Recovery (`PD-001`, `PD-016`, `PF-01`, `PF-55`):** Serialized per-record mutations inside atomic Dexie read-write transactions (verified across 1,000 overlapping concurrent updates); locked buffered editor commits strictly to the originating record key (eliminating blurless cross-note overwrite); added non-destructive Dexie v2 `db.drafts` table and a 1-click **Draft Recovery Inbox** banner in `NotesView`.
- **P0/P1 Security Hardening (`PD-004`, `PD-005`, `PD-014`, `PF-04`):** Added server-side owner passphrase setup, revocable SHA-256 hashed Bearer device tokens, 10-minute pairing codes, workspace-scoped authorization, and Settings device-pairing UI; replaced same-origin Code Studio Worker with an opaque null-origin CSP-locked `<iframe sandbox="allow-scripts">`; added centralized SSRF outbound URL/IP/redirect/size policy (`server/outboundPolicy.ts`).
- **Sync, Verified Attachments & Replacement-Server Recovery (`PD-002`, `PD-003`, `PD-015`, `CONT-003`, `CONT-004`, `PF-02`, `PF-03`, `PF-42`, `PF-51`):** Fixed Fastify v5 wildcard MIME upload parser (eliminating HTTP 415 on PNG/JPEG/WebP/WAV/PDF/SVG); added server & client SHA-256 verification with atomic temp-file staging and safe download headers (`nosniff`, SVG CSP `sandbox`); added automatic missing attachment downloads on clean devices; added `BlobTransferReceipt` tracking so failed blob transfers strictly report `error` instead of `synced`; fixed cross-realm Dexie `db.blobs.put()` data preservation; added SQLite `server_id`/`sync_epoch`, ZIP v3 SHA-256 backup manifests, SQLite backup companion `.manifest.json`, and automatic replacement-server reconciliation.
- **Math, Spreadsheet, CSV & Export Fidelity (`PD-006`, `PD-007`, `PD-008`, `PD-018`, `CONT-006`, `CONT-007`, `PF-08`):** Achieved `117/117` audit reference assertions (pole rejection + golden-section tangent root detection, missing-sheet `#REF!`, zero-length `LEFT`/`RIGHT`, composite embedded formulas like `=SUM(A1:A3)+1`); implemented RFC 4180 CSV state-machine parser; fixed all 7 swapped studio export downloads via typed `downloadFile()`; upgraded HTML Presentation export (`buildPresentationHtmlDeck()`) to embed inline base64 images, HTML tables, rotation, opacity, transitions, and speaker notes.
- **Cross-Engine Compatibility, Offline Precaching, Mobile Layout, Calendar & Packaging (`CONT-005`, `CONT-008`, `PD-009`, `PD-010`, `PD-011`, `PD-012`, `PD-013`, `PD-017`, `PD-019`, `PD-020`, `R-0005`, `R-0007`, `PF-05`, `PF-06`, `PF-07`, `PF-52`):** Deferred `requestPersistentStorage()` with 2500ms timeout after UI mount (fixing Firefox hang); lowered Vite build target to Chrome 74 / ES2019 (verified `0` `?.`/`??` across all 13 built JS files); added build-generated `dist/offline-manifest.json` (19 assets) precached in `public/sw.js`; added responsive `.dp-studio-split`/`.dp-studio-split-3` classes and accessible labels/targets; optimized large-note paste handling; fixed synchronous optimistic Flow Calendar `Adaptive Text` toggle and added smooth vertical drag-to-resize on timed events; upgraded Electron to `39.2.7` with `sandbox: true` & navigation guards; synced release version `4.1.0` and added CI `typecheck && test` gates.
- **Verification:** `12/12` Vitest suites, `178/178` tests passing (`47` existing + `117` audit references + `14` v4.1 repair tests); zero `localStorage`, zero native alert/confirm/prompt, zero `eval`. Live multi-browser, physical device, and owner-authorized production cutover (`CONT-001`, `CONT-009`) remain pending.
