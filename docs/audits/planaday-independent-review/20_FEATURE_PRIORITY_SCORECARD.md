# Proposed feature scorecard

Scores are qualitative estimates from 0 to 10. Higher benefit scores favor priority and higher cost scores indicate greater burden. Foundation issues can outrank feature value. Owners should recalibrate weights after confirming priorities, available hardware, security scope and intended support. No score certifies implementation.

- **User benefit** — Improvement to the intended user workflow.
- **Everyday usefulness** — Frequency in the intended user's work.
- **Cross-feature integration** — Number and importance of connected workflows.
- **Customization value** — Control users gain over views or behavior.
- **Competitive advantage** — Expected differentiation in the intended market.
- **Architectural reusability** — Shareability across Planaday domains.
- **Implementation complexity** — Build and migration difficulty.
- **Maintenance burden** — Ongoing compatibility and operational load.
- **Implementation risk** — Potential reliability, usability or data exposure impact.

In the table, B = user benefit, F = everyday frequency, I = integration, C = customization, D = differentiation, R = reuse, X = complexity, M = maintenance and K = risk.
